# 项目截图

把每个项目的截图放到这里，文件名 = `experiences.json` 里该项目的 `image` 字段：

```
shots/100.qingyuan-01.png   地铁轨道交通查询机系统
shots/101.waima-01.png      歪马送酒微信小程序
shots/102.waima-02.png      歪马送酒中后台系统（供应链）
shots/103.linglong-01.png   京东羚珑营销内容设计平台
shots/104.linglong-02.png   京东千人千面内容营销
shots/106.gitalk.png        Gitalk
shots/107.vue-easy-gantt.png Vue-easy-gantt
shots/108.aotu.io.png       凹凸实验室
```

- 左侧列表用 56×40 的缩略图（`object-fit: cover`），详情页用 16:9 大图。
- 建议一张图同时满足两处：**宽 ≥ 1600px、16:9 或更宽**，主体别贴边。
- 文件不存在时不会报错，只会显示「截图待补」的渐变占位块。
