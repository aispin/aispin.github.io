# 经折 · Accordion Article Room

文稿房间的空间语言原型：一条**经折装**的长纸悬在暗处，一折一篇。读过的折在身后，没读的折沿对角线退进黑暗，当前这一折立起来面对你。

它要替换的是现在 `/posts` 那面 4×N 的卡片墙——18 张已经接近极限，而且没有设计感。关键是**空间轴不撞车**：career 用纵向隧道表示序列，craft 用环形展板表示并列，posts 用一条长卷表示**长度**——篇数涨到 100 只是带子更长，不用改设计。

## 交互

| 操作 | 结果 |
| --- | --- |
| 滚轮 / `↑` `↓` `←` `→` | 翻一折 |
| 拖拽 | 连续翻 |
| 点任意折 | 翻到它 |
| 点**当前这一折** | 打开阅读层（`Esc` / 点空白关） |
| 右上角 `中文` / `EN` | 切换语料 |

## 为什么是 CSS 3D + DOM，不是 three

折页上全是中文标题与正文。走 three 就得把字渲成纹理：缩放会糊、不能选中、不能复制、屏幕阅读器读不到。而折页本身是**平面**——平面用 `translate3d / rotateY` 和 three 的 plane 在视觉上几乎无差别，却省掉整套几何、材质与射线拾取。代价是没有真光照和真阴影，现在的阴影是 `box-shadow` 与手绘的明暗渐变。

## 三个关键数

- 折页基准 `300×420`，单折角 `±24°`，整条带子绕 Y 轴偏 `30°`。折距由 `W·cos(24°)` 推出，两折才是**共边**的真折痕，不是一叠卡片。
- 非焦点折**只留页码与折痕**：巨大的浅色页码压在纸上，标题/摘要/元信息全部隐去。让远处的折显示标题，被前景页遮一半，读起来像 bug。
- 景深三重衰减：`blur` + `brightness(.86)` + `opacity`，配合右侧暗角，带子自己融进黑里，不需要硬裁。

背景只有暖黑底、一束极淡的顶光、64 颗上浮的尘埃——全程序化，没有位图（守全站红线）。
