# 经折 · Accordion Article Room

文稿房间的空间语言原型：一条**经折装**的长纸悬在暗处，一折一篇。读过的折在身后，没读的折沿对角线退进黑暗，当前这一折立起来面对你。

它要替换的是现在 `/posts` 那面 4×N 的卡片墙——18 张已经接近极限，而且没有设计感。关键是**空间轴不撞车**：career 用纵向隧道表示序列，craft 用环形展板表示并列，posts 用一条长卷表示**长度**——篇数涨到 100 只是带子更长，不用改设计。

## 交互

| 操作 | 结果 |
| --- | --- |
| 滚轮 / 触屏滑动 / `↑` `↓` `←` `→` | 翻一折（一次手势只走一格） |
| 拖拽 | 连续翻，每 140px 一格 |
| 点任意折 | 翻到它 |
| 点**当前这一折** | 打开阅读层（`Esc` / 点空白关） |
| 点底部中间的 🔍 或按 `/`、`⌘K` | 顶部滑下目录：搜索标题 / 标签 / 日期，`↑↓` 选、`Enter` 跳 |
| 底部中间的 `中文` / `EN` | 切换语料（房间版没有这一组，见下） |
| 阅读层文末 `← 上一篇` / `下一篇 →` | 不退出阅读层直接翻篇 |

## HUD 为什么全在底边

3D 房子的顶部已经有站级菜单（房间切换、语言、关于），房间再往右上角堆一排控件，视线就得在画面上下两个角之间来回跳。所以这间的东西全压在**底部中间的一条胶囊**里：页码 · 语言 · 搜索。

**房间版的语言跟随房子**：带 `?loc=zh` / `?loc=en` 进来就锁死那一种，并把语言组和两条分隔线一起摘掉（`#bc.is-locked`）。房子切语言时换参数重建这一页即可 —— 两个切换器并存只会互相打架。

```js
const LOCK_LOC = (Q.get('loc') || '').toLowerCase();   // 'zh' | 'en' | null
```

## 输入层是共用的：`public/demos/_pager.js`

滚轮和拖动**不在本页里**，走 `../../_pager.js`（和 `_from.js`、`_lab.css` 一样的公共件）。

`wheel` 不是"一次手势 = 一个事件"：触控板惯性会连发几十个衰减事件，鼠标一格也可能拆成三个。所以判据只用**幅度曲线的形状**，时间只留一个"真的松手了"的 600ms 长阈值 —— 四条任一命中才允许再走一格（详见文件头）。这套数是从 `src/components/ui/CraftHud.jsx` 原样搬来的，那边已经跑了一年。

🔴 拖动**不用** `setPointerCapture`：一旦捕获，浏览器会把随后的 `click` 派发到捕获元素上，`.fold` 的点击就永远收不到 —— 表现就是"点了没反应"。改成 `pointerdown` 记起点、`move/up` 挂 window，再用 `pager.wasDragged()` 吞掉拖动结束后补的那次 `click`。


## 为什么是 CSS 3D + DOM，不是 three

折页上全是中文标题与正文。走 three 就得把字渲成纹理：缩放会糊、不能选中、不能复制、屏幕阅读器读不到。而折页本身是**平面**——平面用 `translate3d / rotateY` 和 three 的 plane 在视觉上几乎无差别，却省掉整套几何、材质与射线拾取。代价是没有真光照和真阴影，现在的阴影是 `box-shadow` 与手绘的明暗渐变。

## 三个关键数

- 折页基准 `300×420`，单折角 `±24°`，整条带子绕 Y 轴偏 `30°`。折距由 `W·cos(24°)` 推出，两折才是**共边**的真折痕，不是一叠卡片。
- 非焦点折**只留页码与折痕**：巨大的浅色页码压在纸上，标题/摘要/元信息全部隐去。让远处的折显示标题，被前景页遮一半，读起来像 bug。
- 景深三重衰减：`blur` + `brightness(.86)` + `opacity`，配合右侧暗角，带子自己融进黑里，不需要硬裁。

背景只有暖黑底、一束极淡的顶光、64 颗上浮的尘埃——全程序化，没有位图（守全站红线）。

## 阅读层

纸**撑满视窗高度**，上下各留 24px（`position:fixed;inset:0` + `padding:24px`，不用 `100vh`——移动端地址栏伸缩时更稳）。页眉（序号 / 日期 / 关闭）不参与滚动，正文自己滚。

🔴 这里必须是 `display:flex; align-items:stretch`，**不能**用 `display:grid; place-items:center`：grid 的 auto 行只在"有富余"时撑高，内容一超就按内容长 —— 长文会把纸撑到 2400px，页眉跟着滚出视窗。同理 `.sheet__body` 要写 `min-height:0`，否则 `overflow:auto` 永远不触发。

文末那块用 `margin-top:auto` 钉在纸底：短稿时落在最下面（纸不会空一大片），长稿时正常跟在正文后。
