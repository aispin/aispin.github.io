把文字 变成卡片背景

输入任意字或词，生成柔和、不抢镜的卡片底纹。Canvas + SVG + GLSL 三层渲染，支持高斯模糊、色彩流动、胶片颗粒。

接入与配置

三步接入，一份配置表。所有参数都能在构造时传入，也能后续通过 update() 修改——点击上方任意卡片即可实时预览。 

# npm
npm install @aiblaze/textural

# 或者用 CDN（单文件，无依赖）
<script src="https://unpkg.com/@aiblaze/textural"></script>
import { Textural } from '@aiblaze/textural';

// 传入容器选择器和配置
const bg = new Textural('#card', {
  text:      '灵感',
  mode:      'tile',    // tile | flow | hero
  blur:      0.3,       // 0 – 1
  hue:       220,
  intensity: 0.6,
  grain:     0.6,
});
// 运行时修改任意配置，会立即重绘
bg.update({
  text: '专注',
  hue:  280,
  blur: 0.6,
});

// 或者换一个词并随机色相
bg.randomize('回声');
// 组件卸载时释放 WebGL context
onUnmount(() => {
  bg.destroy();
});

// 导出当前背景为 PNG
const png = bg.toDataURL();
💡 所有配置项都支持热更新， update() 会保留 WebGL context 与离屏画布，只重绘变化的部分。

配置项

10 options
textstring要渲染的文字，最多 12 个字符
modeenum排布模式：tile 无缝网格 / flow 波浪流动 / hero 超大水印
themeenumlight / dark / auto，auto 会跟随容器背景亮度
blur0 – 1文字高斯模糊强度，越大越隐约
hue0 – 360色相；留空则由文字哈希自动推导
intensity0 – 1文字纹理不透明度
scalenumber字号倍率，相对于容器短边
grain0 – 1胶片颗粒强度，用于消除渐变色带
animateboolean是否启用 GLSL 流动动画
seednumber随机种子；相同种子产生相同底纹
