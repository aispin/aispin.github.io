# 3D 个人站 · 过程沉淀

写文章 / 复盘时要用的素材都丢这里。全是**自包含单文件 HTML** —— 不依赖构建、不依赖任何图片或字体资源，双击就能开，也方便直接贴进文章里当附件。

- 在线预览：`/demos/my-3d-site/`
- 收进来的页面会自动出现在 `/demos/` 索引里

## 门联文案底稿 — `couplets-preview.html`

3D 院子里那副门联的全部文案底稿。

- **39 副**对联：2 副兜底 / 彩蛋（文艺、搞笑）+ 24 节气 + 10 个传统节日 + 3 个法定假期
- 每副都是**七言 + 四字横批** —— 这是 `makeCoupletTexture` 的版式硬约束，不是风格选择
- 每张卡下面是该副对联在 **2026–2027 年的实际命中日期**，由 `src/config/couplets.js` 的解析器实算出来的，不是手写的
- 顶部红框是「今天挂哪副」，随打开日期变

## 加新素材

往这个目录丢 `.html` 就行。跑一次 `node scripts/build-demos-index.mjs`（或直接 `vite dev`，它会自动跑）就会收进索引，并顺手补一份 README。

## 约定

- **自包含** —— 能被 `file://` 直接打开，不发任何网络请求
- **纯文字 / 程序化** —— 不引图片素材（整个项目的约束是零 jpg/png）
- `<meta name="robots" content="noindex">` —— 过程稿不进搜索引擎
- 带 `<meta name="description">` 的话，`/demos/` 索引页的卡片会自动用上
