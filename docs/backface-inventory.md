# 背面清单（L1）· 孤岛院子 v1.2

> 为什么会有这份文档：院子原来是**固定机位**的 —— 相机永远在门楼正前方，
> 背后是什么从来没人看过。v1.2 把相机改成能绕一圈之后，所有"只有朝外一面"
> 的几何都会在某个角度整片消失。这份清单是**取证结果**，不是猜测。

---

## 1. 方法

| 工具 | 干什么 |
|---|---|
| `.workbuddy-ai/harness/probe-backfaces.mjs` | 遍历场景，列出**所有 `side: FrontSide` 的 `PlaneGeometry`**（世界坐标 / 尺寸 / 材质 / 祖先链），按世界 z 分桶 |
| `.workbuddy-ai/harness/probe-island-slab.mjs` | 侧面机位打射线网格，报告每个像素命中的**完整从前到后列表** |
| `.workbuddy-ai/harness/shot-island.mjs` | 四季 × 5 机位 × 横竖屏定妆照（走 `window.__orbit.setPose()`） |

判据只有两条，不需要逐个藏对象试：

- `material.side === FrontSide` ⇒ **从背面直接被剔除**；
- `PlaneGeometry` ⇒ **厚度为零**（Box / Cylinder 无所谓朝向）。

⚠️ 绕后看时**先问一句"它被挡着吗"**：院子的后罩墙（顶 1.85）会把院子里
几乎所有低于 1.85 的东西挡住。所以"单面"不等于"看得见的洞" ——
下表专门有一列标这个。

## 5. 剩下的洞（建议按这个顺序做）

### WO-B1 · 入口的透明 billboard（大树 / 灯笼 / 花丛）

- **症状**：`MeshBasicMaterial{ transparent: true }` 的 6×8 大树平面，从背后
  整片消失（只剩树干）。灯笼、花丛同理。
- 🔴 **为什么不能"顺手加个 `DoubleSide`"**：这些是**透明**材质。单个四边形
  开双面时，背面的片元与正面**深度相同**，而 three 默认 `depthFunc =
  LessEqualDepth` ⇒ 背面那一遍**照样通过深度测试**、再混一次 ⇒ 树冠的
  alpha 大约翻倍（前视图会变浓）。**前视图是主视图，不能为了背面牺牲它。**
- **建议修法**（待定）：给每个 billboard 补一块 `z − 0.02`、`side: BackSide`
  的孪生面，并让孪生面**晚于**主面绘制（`renderOrder` 更高）—— 这样从正面
  看，孪生面被主面写下的深度剔除；从背后看，主面被剔除、孪生面补上。
  ⚠️ 需要先确认主面确实 `depthWrite: true`（默认是），并且**两边的
  renderOrder 都要实测**，不能推。

### WO-B2 · 高仰角下露出来的门扇

- **症状**：仰角 50°、半径 15 时相机在 `(0, 11.6, 3.55)` —— 正好在后罩墙
  **外侧 0.6 单位**、墙顶上方 9.75，于是**越过墙头俯瞰院子**，门扇 / 门框 /
  门墩（全是不透明单面）从背后看会消失。
- **建议修法**：这几个都是**不透明**材质，直接 `side: DoubleSide` 是安全的
  （不透明材质双面同深度不会双混）。

### WO-B3 · 走廊外壳的收尾（DR）

- 外壳目前从 `COURT_BACK_Z`（4.15）拉到 `z = −14`，再往 −z 的走廊段靠雾收掉。
  春雾 far = 66，理论上 z < −47 才完全入雾 —— 也就是说**春天侧看时，外壳
  尽头之后那一小段走廊还隐约可见**。
- 这是"要不要把岛做大 / 把外壳拉长"的设计决定，不是 bug，所以列成 DR。

## 6. 复现

```bash
# 1. 起 preview（prod 包，不是 dev —— dev 冷启动慢得多）
npm run build && npm run preview            # http://localhost:4173

# 2. 取证：所有单面平面
node .workbuddy-ai/harness/probe-backfaces.mjs http://localhost:4173 spring 21 46

# 3. 取证：某个机位下屏幕上一片白是什么
node .workbuddy-ai/harness/probe-island-slab.mjs http://localhost:4173 1.5708 0.22 22

# 4. 定妆照（四季 × 5 机位 × 横竖屏）
node .workbuddy-ai/harness/shot-island.mjs http://localhost:4173 .workbuddy-ai/shots/island-v12
```

🔴 **`setPose` 必须吸附**（第 4 个参数默认 `true`）。`settleLerp` 的插值系数
是**每帧固定**的，软件渲染下只有个位数 fps，从 yaw = 1.5π 转到 0 需要 ~70 帧，
而截图只等 1.2 s —— 第一轮 `rest` 定妆照就是这么拍错的（拍成了"从左侧斜看
院墙"）。现在脚本每条日志都带 `poseErr`，> 0.05 就是没吸附上。
