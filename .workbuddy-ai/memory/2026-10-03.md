## 音乐房/档案室「乱乱的」修复（headless 全链路复现 + 修复）

根因链（4 个独立问题叠加）：

1. **CJK 字体缺字 → jsdelivr CDN 依赖**：`maple-3d.woff` 只有 91 个 CJK 字（缺「房、档、案」等 164 个站点用字），中文模式下 drei Text (troika) 会回退到 `unicode-font-resolver` 的 jsdelivr CDN（国内不可靠）。修复：下载 Maple Mono CN v7.9 全量字体，用 fontTools 按站点全部 169 个 CJK 字符 + ASCII + 常用符号子集化为 `public/fonts/maple-cn.woff`（107KB），`theme.js TEXT.font3d` 指向它。鸭子语录里的 emoji（🤷🚀）已移除（任何 woff 都无法覆盖 emoji，必触发 CDN）。
2. **ContentRoom Html transform 面板世界尺寸失控**：`<Html transform distanceFactor={11}>` 世界足迹 = clientWidth×df/400 = 900px→24.75×17 世界单位，盖满 24×16 背墙并占视口 ~94%×115% → 用户看到的「乱乱的」。且 transform 模式（CSS3D）在侧房间旋转坐标系下定位不可靠（DOM 中心投影到 (174,203) 而墙心正确投影 (802,568)）。修复：改 billboard 模式 `<Html position={[0,-1.7,-10]} center zIndexRange={[30,10]}>`，面板恒定 900×620 屏幕像素，验证 posts (309,114) / music (5,110) 全部完整在屏。
3. **路由清空 query string**：`useDocumentMeta` 的 `history.replaceState(path)` 丢掉 `?noloader=1` 等 query → App.jsx 每次渲染重读 `location.search` 导致 Preloader 复活盖住全部点击。修复：App.jsx 模块级 `NO_LOADER` 常量只读一次；`noloader` 模式下自动 `setIsLoaded(true)`（否则 PaperTransition 不挂载、传送流程卡死）；router replaceState/pushState 保留 `location.search`。
4. **headless 验证工作流**（puppeteer-core + chrome-headless-shell-1234，flags: `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`）：`/tmp/probe16.js` 走完整用户流——点左入口门(734,550)（有 flaky，重试+换(866,550)交替）→ deep-link `/music?noloader=1` 自动 teleport → 轮询 `.content-room-panel` → dump 相机/面板 rect。入口门点击不可靠的原因是音频 mp3 blob fetch 偶发失败（仅 headless）。

其他：EntranceDoors FONT_URL 从 gstatic Inter 改本地 `/fonts/CabinSketch-Bold.ttf`；SW VERSION → `aispin-v3`。
