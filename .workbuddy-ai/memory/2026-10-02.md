### 选型结论
**以 portfolio-itom 为底座**：3D 是核心价值，90 个 JSX/Shader 组件不能丢；用 Nuxt 做底座需把整个 3D 用 TresJS 重写。
profile 的重资产是 109 个内容文件（与框架无关），而非约 700 行 Vue。原则：**搬内容，不搬框架**。

- AI+ 数据 = 构建脚本 + Actions 定时刷新（每周，带 GITHUB_TOKEN），JSON commit 进仓库，构建不联网。

### ITomPoland/ui-components 评估（仅讨论）
仓库 `ITomPoland/ui-components` = "ITOM UI Sketchbook Vol.1"，9 个 vanilla JS/CSS 组件，GSAP 驱动。
本地无此目录，需从 GitHub 取（`gh api repos/ITomPoland/ui-components/tarball/master`）。
该仓库 AGENTS.md 明令禁止引入框架/Tailwind，所以**不能安装，只能移植逻辑**（每个组件 JS 仅 85–304 行）。
高契合：messy-stacking-sections（纸堆叠，配纸感主题）、curved-arc-carousel（数学驱动的弧形卡列）。
中契合：split-text-preloader（架构可借鉴）、magnetic-button、kinetic-text-button、train-flow-preloader。
低契合：magnetic-glass-button（深色玻璃拟态，与暖色动漫风冲突）、liquid-gooey-button（液态科幻感）、
transition-shrink-slide（依赖 Barba.js，MPA 专用，本项目是 SPA + 已有 PaperTransition）。
