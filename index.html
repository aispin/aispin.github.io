AISPIN | 温馨动漫风的 3D 个人主页

这是一个用 React Three Fiber 构建的沉浸式 3D 个人网站：你将走进一条手绘风格的温暖走廊， 沿途的八扇门通向八个房间——ABOUT 档案、GALLERY 摄影、STUDIO 项目与实验室、POSTS 文章、 VIDEOS 短视频、MUSIC 原创、AI+ 技能，以及 CONTACT 联系方式。走廊尽头还挂着一枚通往小说站 ZeoBooks 的书签挂件。

  • 关于我 / About
  • 摄影 / Gallery
  • 项目与实验室 / Studio
  • 文章 / Posts
  • 短视频 / Videos
  • 音乐 / Music
  • AI Skills / AI+
  • 联系 / Contact
  • 小说 / Novels (ZeoBooks)

关于 AISPIN

AISPIN 是一名开发者与创作者：写代码、做 AI 技能、拍照片、写文章、做音乐。 这个网站本身就是一份作品——整站基于 React Three Fiber 与 Three.js， 搭配 GSAP 动画与 Maple Mono 字体，支持中英双语、明暗模式与 PWA 离线安装。

AI+ 房间：AI Skills 与应用

AI+ 房间陈列 AISPIN 在 GitHub 上开源的 iskill- 系列技能包与 ai- 前缀应用， 数据由 GitHub Actions 每周自动刷新，欢迎在房间里逐个翻阅。
